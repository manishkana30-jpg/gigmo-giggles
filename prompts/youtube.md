# YouTube Metadata & SEO Prompt Guidelines

1. **Title Rules**:
   - Maximum 70 characters for optimal mobile readability.
   - Include 1 relevant emoji (e.g., 🌧️, 🚀, 🌳).
   - Clear educational question or exciting hook.
   - Example: *"Why Does Rain Happen? 🌧️ | Fun Science for Kids | Gigmo Giggles"*
   - No sensationalist or misleading clickbait.

2. **Description Format**:
   - Paragraph 1: Child-friendly summary of the episode's story and learning objective.
   - Paragraph 2: Interactive quiz question recap so parents can quiz kids.
   - Paragraph 3: Standard call-to-action (Subscribe, Like, Share) + Show credits.
   - Section 4: Timestamps / Chapter marks for each scene.
   - Section 5: Relevant hashtags (e.g., `#KidsLearning #ScienceForKids #GigmoGiggles`).

3. **Tags**:
   - 15–20 high-relevance tags targeting educational kids queries (e.g. "kids cartoon science", "preschool learning", "educational videos for children").

4. **Category & Audience**:
   - Category: "Education" (YouTube Category ID 27).
   - COPPA: "Made for Kids" compliance declared explicitly.
