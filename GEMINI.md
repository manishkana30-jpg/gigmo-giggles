# 📝 Workspace Rules & Customization: Gigmo Giggles Pipeline

This file defines the canonical rules, constraints, and guidelines for the Gigmo Giggles children's show pipeline. Antigravity agents working in this workspace must adhere to these rules at all times.

---

## 👥 Canonical Characters

The show features **Jack** and **Jill** as the main characters. Ensure that their visual descriptions and emotion prompts are preserved exactly:

- **Jack**: Spiky black hair, navy blue glasses, wearing a white graphic t-shirt and green shorts.
- **Jill**: Red bow headband, long wavy reddish-brown hair, dark rose short-sleeve top with a white pearl necklace.
- Visual prompts must match the specs defined in `config/characters.json` and `config/character_prompts.json`.

---

## 🗣️ Spoken Language & Subtitle Burn-In

To deliver Hindi language content to English-subtitled audiences, follow these translation and styling rules:

1. **Spoken Audio**: Spoken dialogue must use the natively translated Hindi text (`translated_text` / `translated_narration`) synthesized with `gtts_lang="hi"`.
2. **Subtitles**: Subtitles must display the English text (`text` / `narration`) on screen.
3. **Subtitle Styling**: Subtitles must be burned into the bottom center of the video with the following exact filter parameters:
   - **Font size**: `24`
   - **Font**: `Arial Bold`
   - **Position**: `Alignment=2` (Bottom Center)
   - **Vertical Margin**: `MarginV=15` (Stays cleanly at the bottom edge)
   - **Colors**: White primary text with a black outline and semi-transparent background box.

---

## 🗑️ Safe SRE Resource Purging

When scanning directories to clean up temporary build/media files:
- **Rule**: **NEVER** search the project root (`Path(".")`) recursively (`rglob`) or scan folders containing source code (`src/`) or configuration files (`config/`).
- **Target Directories**: Purges must be restricted strictly to `./episodes/` and system temporary directories (like `/tmp` on Linux).

---

## 🧪 Mock Generator and Schema Compliance

For offline verification and testing (the `--mock` flag):
- **Rule**: The mock episode dictionary generated by `_generate_mock_episode` in `src/gemini_creator.py` must match `EpisodeSchema` (Pydantic validation) exactly.
- **Topics**: 
  - If topic is `"The Lost Compass Adventure"`, return the 4-scene Jack/Jill adventure.
  - If topic is any other dynamic test topic, return the 4-scene Bobo/Luna adventure to ensure all existing test suites remain green.
- **Required Fields**: Ensure `episode_id`, `topic`, `quiz`, `youtube`, `thumbnail`, and `shorts` are populated at all times.

---

## 🔍 Quality Audit Gate before Publishing

To guarantee zero-defect broadcasts:
- **Rule**: Quality Gate Verification (`QualityGateValidator.check_quality_gate`) must always execute **before** YouTube upload publishing.
- **Halt on Failure**: If any quality or safety check fails, the pipeline must immediately raise an exception (`ValueError`) and abort/prevent the publishing stage.

---

## 🚀 GitHub Actions Workflow Security

All multi-line scripts in `.github/workflows/*.yml` must be hardened using:
- `set -euo pipefail`
- Unbuffered python execution (`python -u`)
- Explicit `permissions: contents: read` to prevent write access unless specifically needed.
- Generated MP4 media files must be uploaded as workflow run artifacts rather than committed to the repository to avoid repository bloat.
