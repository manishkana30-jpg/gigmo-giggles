# Storyboard Generation Guidelines

For each scene in the episode, the storyboard must specify:
1. `scene_number`: 1-indexed sequential integer.
2. `duration_seconds`: Calculated timing matching character dialogue length + transition beats.
3. `location`: Descriptive setting name (e.g., "The Wonder Treehouse Lab", "Sparkle Riverbank").
4. `action`: Explicit staging notes for character movements, poses, and props.
5. `camera_movement`: Ken Burns movement style (e.g., "slow_zoom_in", "pan_left_to_right", "tilt_up", "static_focus").
6. `visual_focus`: Key educational diagram or focal object in frame.
7. `transition`: Transition to next scene ("crossfade", "slide_left", "circle_wipe", "cut").
